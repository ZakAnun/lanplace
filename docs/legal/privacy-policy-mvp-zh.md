# 蓝域（BlueScopes）隐私政策（MVP）

**开发者：** 李铭淋  
**联系邮箱：** linhenji@163.com  
**生效日期：** 2026-11-14

## 1. 引言

蓝域（BlueScopes）由开发者李铭淋提供。本应用无注册账号、无自有后端服务器，**不新增任何服务器**，**不会将扫描、连接、探测或日志结果上传至开发者服务器**。

## 2. 我们处理的信息

### 2.1 蓝牙相关信息

当您使用「附近设备发现」或相关功能时，本应用会通过系统蓝牙能力扫描 **周围** 正在广播的设备（不限于家庭环境），并在 **本机屏幕** 展示例如：

- 设备标识（如系统提供的设备 ID / 地址）  
- 设备名称（若广播或系统提供）  
- 信号强度（RSSI）  
- 是否可连接  
- 自广播数据解析出的技术信息（如服务 UUID、制造商数据等摘要）  

当您在设备工作台 **主动点选「连接」** 时，本应用会通过系统 GATT/BLE 能力与您所选设备建立连接，并可在您操作下读写特征、订阅 Notify。连接由您发起，**不会自动连接**。连接过程、服务树与特征值 **仅在本机展示**，不上传。

### 2.2 局域网（mDNS）相关信息

在您 **已连接 Wi‑Fi**（家庭、公司、公共热点等任意网络）且主动使用该功能时，本应用会在 **当前所连 Wi‑Fi 的局域网内** 通过系统 mDNS 能力发现 **主动对外宣告** 的服务（例如部分智能家居、投屏、打印机等设备使用的 `_hap._tcp`、`_googlecast._tcp`、`_airplay._tcp`、`_ipp._tcp`、`_http._tcp` 等类型），并在本机展示例如：

- 服务名称  
- 服务类型  
- 设备 IP 地址与端口（在系统解析成功后）  

当您在局域网设备工作台 **主动发起端口探测或 HTTP 探测** 时，本应用会向该设备已解析的局域网 IP 与端口发送 **TCP 连接尝试** 或 **HTTP GET**，并在本机展示端口是否开放、HTTP 状态码及正文预览（截断）。探测仅针对您当前查看的那台设备，由您触发，**不扫描全网段**，结果不上传。

本应用 **不进行** 全网段 IP 扫描，也 **无法** 列出路由器后台中的全部已连接终端。公共或访客 Wi‑Fi 若启用客户端隔离，可能无法发现同网段其他设备，此时通常仍可扫描周围蓝牙设备。

### 2.3 Wi‑Fi 相关信息

为便于您确认当前网络环境，本应用可能读取 **当前已连接 Wi‑Fi 的名称（SSID）** 并在发现页展示。该信息 **仅用于界面展示**，不上传。

### 2.4 存储与保留

上述信息 **仅在当前使用期间用于展示**，默认 **不写入持久化存储**（隐私同意状态等必要偏好设置除外）。设备工作台的会话日志（如 GATT 连接、LAN 探测、读写事件）仅保存在 **内存** 中；关闭或卸载应用后不再保留扫描结果与会话日志。

您可 **主动导出** 日志文本到系统分享面板；导出由您发起，应用 **不会自动上传** 至任何服务器。

### 2.5 演示模式

在系统模拟器或开发者启用的演示模式下，应用可能展示 **模拟的蓝牙或局域网设备数据**，便于界面预览，不代表真实周围环境。

### 2.6 隐私政策链接

您可通过应用内链接 **在系统浏览器中** 打开 HTTPS 隐私政策页面。页面加载由系统浏览器完成。**不接入第三方数据分析、广告或统计 SDK。**

## 3. 权限说明

| 类型 | 权限（HarmonyOS） | 用途 |
|------|-------------------|------|
| 设备发现和连接 | ohos.permission.ACCESS_BLUETOOTH | 扫描并展示周围蓝牙设备；在您主动操作时与所选设备建立 GATT 连接 |
| 网络 | ohos.permission.INTERNET | 通过系统 mDNS 在同 Wi‑Fi 下发现局域网服务；在您主动操作时对所选设备做 TCP/HTTP 探测（数据不上传至开发者） |
| Wi‑Fi 信息 | ohos.permission.GET_WIFI_INFO | 读取当前 Wi‑Fi 名称以便在发现页展示 |

您可在系统「设置 → 应用 → 蓝域 → 权限」中管理上述权限；拒绝相关权限可能导致对应功能不可用（例如无蓝牙权限则无法展示蓝牙设备或发起 GATT 连接，未连接 Wi‑Fi 时通常无法发现局域网 mDNS 服务或进行探测）。

## 4. 第三方

**本 MVP 版本不包含第三方 SDK。**

## 5. 您的选择

- 可拒绝或撤销蓝牙、网络、Wi‑Fi 信息权限；相应发现、连接或探测能力将受限。  
- 可选择不发起 GATT 连接、LAN 探测或日志导出。  
- 不同意本政策时，可选择退出应用。

## 6. 政策更新

我们可能更新本政策；重大变更将在应用内或通过更新说明提示。更新后的政策文本以本页面及链接地址所示为准。
